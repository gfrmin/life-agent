The paragraph and law 9 are struck, and MODEL §4 now says plainly that retrieved chunks go to a cloud model and the deliberative rung can search the whole corpus. The disclosure record (rule 3, law 7) is still owed (written 2026-09-30, PR: the disclosure record).
6. 2026-09-30 — Owner: "no such thing as 'mechanics', everything is a decision": every choice on the ask path is a row of the one argmax. Done here: which transform to buy and which candidate to answer with are rows of `core/decide.bayes_act` (one `gather` row per open probe, one `respond` row per candidate); `core/enact.py` no longer picks, and a drift gate fails if it calls `max`, `min` or `sorted`. The no-candidate state is decided like any other (candidates `[]`, `p1` = 0): the executor no longer walks the probe menu by itself, and at the current gauge an empty extraction abstains. The fourth is done too: whether to attempt a question the router calls not a point fact is a row of `bayes_act`'s argmax (`decide.route_options`, ranked by `decide.choose`), priced from the router's verdict as an observation of the answer type by a measured row (`core/route_row.py`); all four choices on the ask path are rows, and `decide_via_loop` no longer declines on its own.
7. 2026-09-30 — Owner: "the board is just a (biased) sample, it's the expected loss that matters"; and, approving the new text, "ultimately there's only one rule: Bayes theorem (and maximising expected utility)". **Rule 5 is replaced: the loss decides; the board is evidence.** The old rule vetoed any change under which a pinned set's realised utility fell (E[ΔU] ≥ 0 on every row, usually over one run). A pinned set is one draw from a biased sample, so a fall is now explained in the PR, not vetoed; a change merges when it is an equivalence or a row of the argmax with a declared, measured outcome model; the board is read for expected utility and calibration, master against branch. A "never wrong" preference is `u_wrong`'s, never a gate. `eval.score --gate` becomes `--falls` and no longer fails the run. The model for this is hkaddresses' rulings 26a, 59 and 88.
8. 2026-09-30 — Owner: partial answers are the document, not a hedged value. A new action `cite` names the one document believed to hold the answer without asserting the value, one row per document in `core/decide.bayes_act`, at `P(g)`, the summed credence of the candidates that document reports. Gauge priors: `u_cite_right` +0.5, `u_cite_wrong` −1 ("a right pointer is half a right answer; a wrong one costs one read"); both optional latents, read at those means when a model file omits them. Graded by attestation of the cited document; counted in their own board columns, never as right, wrong or declined; reactions to a cite are recorded and not folded.
